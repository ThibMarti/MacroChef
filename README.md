# MacroChef

Conversational AI meal-planning assistant. Set your dietary preferences and macro targets, get a generated meal plan, then refine it by chatting — swap a meal, tweak an ingredient, all in natural language.

Built during Le Wagon's AI Software Development Bootcamp (2026), in a team of 4, over 1 week.

## How it works

Users set their preferences (diet, macro targets) and GPT-4o (via the `ruby_llm` gem) generates a personalized meal plan. From there, a chat interface lets you refine it conversationally — swap a meal, add or remove an ingredient — and a recipe library lets you browse and favorite what you like.

## Stack

Ruby on Rails 8 · PostgreSQL · GPT-4o (ruby_llm) · Devise · Hotwire (Turbo/Stimulus) · Bootstrap
